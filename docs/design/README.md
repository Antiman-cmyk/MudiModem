# docs/design — historical design notes

Design notes written while each feature was first built (2026-07 … 2026-09). They record
*why* things are the way they are — probe results, rejected options, trade-offs.

They are **background, not instructions**: nothing here is a checklist to follow or a process
to obey, and where a note disagrees with the code, `docs/architecture.md`,
`docs/cellular-api-4.10.md` or the firmware image, those win. Notes from before 2026-09-02
describe GL firmware 4.8 unless they say otherwise.
